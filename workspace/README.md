# Workspace Demo Karat 🦀

Selamat datang di **Karat IDE**! Folder ini adalah taman bermain untuk mencoba semua fitur.

## Coba ini 👇

1. **Editor** — buka `hello.rs`, ubah sesuatu, tekan `Ctrl+S`. Perhatikan titik
   di tab saat ada perubahan yang belum disimpan.
2. **Quick open** — tekan `Ctrl+P`, ketik `todo`, Enter.
3. **Command palette** — tekan `Ctrl+Shift+P`, ketik `theme`, Enter.
4. **Search** — tekan `Ctrl+Shift+F`, cari kata `karat`.
5. **Terminal** — tekan `` Ctrl+` `` lalu jalankan:
   ```bash
   python3 demo.py
   ```
6. **Run** — buka `demo.py`, lalu jalankan perintah *Run: Run Active File*
   dari command palette (atau tombol ▶ di activity bar).
7. **Git** — edit file apa pun, lalu buka *Source Control* di activity bar:
   stage → tulis pesan → commit. Branch aktif tampil di statusbar.
8. **New file** — klik ikon di Explorer, coba nama `web/app.js` (folder
   otomatis dibuat).

Selamat ngoding! ✨
