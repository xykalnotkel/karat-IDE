# Changelog

## 0.2.0

- Rebranded Karat as an open-source IDE developed by XySpace.
- Added signed Windows and Android release pipelines.
- Added Android ARM 32-bit and ARM 64-bit artifacts.
- Added terminal profiles for common Windows and Unix shells.
- Added folder-based declarative extensions and an Extensions panel.
- Moved the default desktop workspace under the user's home profile.
- Added quiet Fluent/Surface styling and refreshed application icons.
- Bundled WebView2 for fully offline Windows installation.
- Hardened web authentication and filesystem path containment.

## 0.1.0

- Initial Monaco editor, explorer, search, Git, PTY terminal, web backend, and Tauri desktop shell.
