# Governance

Karat is an open-source project developed and stewarded by **XySpace**.

- **Maintainers** review releases, security changes, architecture, and branding.
- **Contributors** propose changes through issues and pull requests.
- Decisions prefer technical merit, user safety, accessibility, portability, and maintainability.
- Substantial changes should begin with a public design issue or discussion.
- Security reports follow `SECURITY.md` and are handled privately before disclosure.

Consistent contributors may be invited as reviewers or maintainers. Maintainer access follows least privilege and may be removed after prolonged inactivity or violations of the Code of Conduct.
